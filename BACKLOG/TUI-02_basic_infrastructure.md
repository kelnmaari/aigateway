# TUI-02: Базовая TUI инфраструктура

## Описание
Создание основы для терминального пользовательского интерфейса с Bubbletea.

## Задачи
- Создать основное TUI приложение в `cmd/tui/main.go`
- Реализовать базовую модель приложения (Bubbletea model)
- Настроить роутинг между экранами
- Создать базовые стили в `internal/tui/styles/`
- Реализовать горячие клавиши и навигацию

## Цель
Подготовить инфраструктуру для всех TUI экранов.

## Приоритет
**Высокий** - основа для всех TUI компонентов
