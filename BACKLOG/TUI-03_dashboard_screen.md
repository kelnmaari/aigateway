# TUI-03: Dashboard экран

## Описание
Создание главного dashboard экрана с отображением основных метрик системы.

## Задачи
- Создать главный dashboard в `internal/tui/views/dashboard.go`
- Реализовать отображение основных метрик:
  - Статус сервера (running/stopped)
  - Количество активных запросов
  - Общее количество запросов за сессию
  - Использование CPU/Memory (если доступно)
- Добавить ASCII charts для визуализации метрик
- Реализовать автообновление данных

## Цель
Предоставить центральный экран для мониторинга состояния системы.

## Приоритет
**Высокий** - основной экран для администраторов

## Фаза
11 - Terminal User Interface (TUI)

## Оценка времени
6-8 часов
