**Integration**:

```go
// CSRF Protection middleware (v2.4.9+) - Go 1.25 CrossOriginProtection
if r.config.Server.CORS.Enabled {
    csrfConfig := middleware.CrossOriginProtectionConfig{
        Enabled:             true,
        TrustedOrigins:      r.config.Server.CORS.AllowedOrigins,
        RequireOriginHeader: false,
    }
    r.engine.Use(middleware.CrossOriginProtection(csrfConfig, r.logger))
    r.logger.WithField("trusted_origins", csrfConfig.TrustedOrigins).
        Info("CSRF protection middleware enabled (Go 1.25)")
}
```

**What it does**:
- ✅ Validates `Sec-Fetch-Site` header (97% browser support)
- ✅ Blocks cross-origin POST/PUT/DELETE from untrusted origins
- ✅ Uses trusted origins from CORS configuration
- ✅ Allows GET/HEAD/OPTIONS (safe methods)
- ✅ Allows API clients (no `Sec-Fetch-Site` header)

### ✅ **FlightRecorder** (Go 1.25 Production Debugging)

**File**: `cmd/server/main.go:79-103`

**Integration**:
```go
// FlightRecorder для production debugging (v2.4.9+)
flightRecorder := debug.NewFlightRecorderManager(debug.FlightRecorderConfig{
    Enabled:         true,
    MinAge:          30 * time.Second,
    MaxBytes:        10 * 1024 * 1024, // 10MB
    OutputDir:       "traces",
    AutoSaveOnPanic: true,
}, appLogger)

if err := flightRecorder.Start(); err != nil {
    appLogger.WithError(err).Warn("Failed to start FlightRecorder")
} else {
    defer flightRecorder.Stop()
    appLogger.Info("FlightRecorder started (Go 1.25)")
}

// Panic recovery с trace saving
defer func() {
    if r := recover(); r != nil {
        flightRecorder.SaveTraceOnPanic(context.Background(), r)
        appLogger.WithField("panic", r).Fatal("Application panicked - trace saved")
        panic(r)
    }
}()
```

**What it does**:
- ✅ Records last 30 seconds of trace (rolling window)
- ✅ Auto-saves to `traces/` directory on panic
- ✅ Max size: 10MB (configurable)
- ✅ Graceful shutdown (`defer recorder.Stop()`)

**Log output**:
```
[INFO] FlightRecorder started (Go 1.25) - production debugging enabled
       min_age_sec=30 max_bytes_mb=10 output_dir=traces

# On panic:
[ERROR] Application panicked - trace saved to traces/
        panic="runtime error: nil pointer dereference"
        file=traces/trace-panic-20251104-143025.trace
        size_mb=2.4
```

**Analyzing saved trace**:
```bash
# Open trace in browser
go tool trace traces/trace-panic-20251104-143025.trace

# Extract specific goroutine
go tool trace -pprof=goroutines traces/trace-panic-*.trace > goroutines.txt
```
