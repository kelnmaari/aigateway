Features

Everything You Need to Run AI at Scale

A complete platform for deploying, managing, and scaling large language models in your own infrastructure.

Multi-Provider Inference

Run models on vLLM, SGLang, TGI, llama.cpp, and TEI simultaneously. Auto-manage Docker containers with GPU allocation.

OpenAI-Compatible API

Drop-in replacement for OpenAI API. Works with any client that supports /v1/chat/completions, /v1/models, and /v1/embeddings.

Docker-Based Deployment

One-click model deployment via Docker. Automatic GPU detection, tensor parallelism, health checks, and container lifecycle management.

RAG Pipeline

Built-in Retrieval-Augmented Generation with PgVector and Qdrant. Index documents, generate embeddings, and enrich LLM context.

Enterprise Security

JWT authentication, LDAP/OIDC SSO, RBAC with multi-tenancy, API key management, rate limiting, quotas, and audit logging.

Monitoring & Analytics

Prometheus metrics, real-time dashboards, usage analytics per user/tenant, container logs, and system health monitoring.
