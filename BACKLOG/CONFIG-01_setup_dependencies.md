# CONFIG-01: Конфигурация и зависимости

## Описание
Настройка всех необходимых зависимостей проекта и создание системы конфигурации.

## Задачи
- Добавить необходимые зависимости в `go.mod`:
  - Gin web framework
  - Viper для конфигурации
  - Logrus для логирования
  - Testify для тестирования
  - Bubbletea ecosystem (bubbletea, lipgloss, bubbles)
  - Authentication: bcrypt, golang.org/x/crypto/argon2
  - Rate limiting: golang.org/x/time/rate
  - Storage: modernc.org/sqlite (опционально)
- Создать базовую структуру конфигурации в `internal/config/`
- Реализовать загрузку конфигурации из env переменных и файлов
- Создать базовую настройку логирования

## Цель
Подготовить все зависимости и систему конфигурации для разработки приложения.

## Приоритет
**Высокий** - необходимо для всех последующих компонентов

1 - Инициализация проекта
