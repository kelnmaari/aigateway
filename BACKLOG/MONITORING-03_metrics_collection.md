# MONITORING-03: Metrics Collection

## Описание
Создание системы сбора и хранения метрик для TUI и мониторинга.

## Задачи
- Создать систему сбора метрик в `internal/metrics/`
- Интеграция с HTTP server для сбора данных о запросах
- In-memory storage для метрик (ring buffer)
- Агрегация данных (average, min, max, count)
- Периодическая очистка старых данных

## Цель
Обеспечить надежный сбор метрик для отображения в TUI и мониторинге.

## Приоритет
**Высокий** - необходимо для TUI dashboard
