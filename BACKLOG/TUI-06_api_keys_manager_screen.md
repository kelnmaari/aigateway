# TUI-06: API Keys Manager экран

## Описание
Создание полнофункционального TUI экрана для управления API ключами.

## Задачи
- Отображение списка всех API ключей
- Создание нового API ключа с настройкой прав доступа
- Редактирование существующих ключей (модели, rate limits)
- Revoke/Enable API ключей
- Просмотр статистики использования каждого ключа
- Фильтрация и поиск по ключам
- Генерация QR кодов для ключей (опционально)

## Цель
Предоставить полноценный инструмент для управления API ключами через TUI.

## Приоритет
**Критический** - основной инструмент для управления безопасностью

## Фаза
11 - Terminal User Interface (TUI)

## Оценка времени
6-7 часов
