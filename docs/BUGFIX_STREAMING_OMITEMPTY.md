# 🐛 BUGFIX: Stream Field omitempty Causing Partial Responses

**Date:** 2025-10-23  
**Version:** 1.X.Y  
**Severity:** 🔴 **CRITICAL**  
**Impact:** All non-streaming requests

---

## 📝 Problem Description

### Symptoms

- **AI-review** tool received only **one word** instead of full response
  - Examples: `"The"`, `"It"`, `"```"`, `"Based"`
- **All non-streaming clients** experienced same issue
- Ollama was returning **streaming chunks** even for non-streaming requests

### Root Cause

```go
// BEFORE (BROKEN):
type ChatRequest struct {
    Model    string        `json:"model"`
    Messages []ChatMessage `json:"messages"`
    Stream   bool          `json:"stream,omitempty"`  // ❌ BAD!
    ...
}
```

**Problem with `omitempty`:**

1. When `Stream == false` (default), JSON omits the field entirely
2. Request to Ollama: `{"model": "...", "messages": [...]}` ← **NO `stream` field!**
3. Ollama uses **its own default behavior** = **STREAMING MODE**
4. Ollama sends multiple JSON chunks separated by newlines
5. `json.NewDecoder` reads **only first chunk** (first word)
6. Rest of response is ignored

### Example of Broken Flow

```json
// Request to Ollama (generated by proxy):
{
  "model": "qwen2.5-coder:7b",
  "messages": [...]
  // ❌ MISSING: "stream": false
}

// Ollama's streaming response:
{"message": {"content": "The"}, "done": false}
{"message": {"content": " code"}, "done": false}
{"message": {"content": " looks"}, "done": false}
...
{"message": {"content": " good"}, "done": true}

// Proxy reads ONLY FIRST line:
{
  "choices": [{"message": {"content": "The"}}]  // ❌ ONE WORD!
}
```

---

## ✅ Fix

### Code Change

**File:** `internal/client/ollama/models.go`

```go
// AFTER (FIXED):
type ChatRequest struct {
    Model    string        `json:"model"`
    Messages []ChatMessage `json:"messages"`
    Stream   bool          `json:"stream"`  // ✅ REMOVED omitempty
    ...
}
```

### Effect

**Before:**
```json
{
  "model": "qwen2.5-coder:7b",
  "messages": [...]
  // ❌ stream field missing → Ollama uses streaming
}
```

**After:**
```json
{
  "model": "qwen2.5-coder:7b",
  "messages": [...],
  "stream": false  // ✅ Explicit → Ollama returns full response
}
```

## 🔍 Why This Happened

### Design Flaw

The `omitempty` tag is commonly used to **reduce JSON payload size**, but it's **dangerous for boolean fields** with meaningful `false` values:

```go
// SAFE omitempty (optional string):
Format string `json:"format,omitempty"`  // ✅ OK if missing

// UNSAFE omitempty (boolean with semantic false):
Stream bool `json:"stream,omitempty"`  // ❌ BAD! false != missing
```

### Lesson Learned

**Rule:** Never use `omitempty` on boolean fields where `false` has semantic meaning different from "not specified".
