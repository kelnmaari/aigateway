# TUI-07: Configuration Viewer

## Описание
Создание экрана для просмотра и редактирования конфигурации сервера.

## Задачи
- Отображение текущей конфигурации сервера
- Возможность просмотра всех настроек
- Hot-reload конфигурации (если поддерживается)
- Валидация конфигурационных изменений
- Экспорт конфигурации в файл

## Цель
Упростить управление конфигурацией через терминальный интерфейс.

## Приоритет
**Средний** - удобство администрирования

## Фаза
11 - Terminal User Interface (TUI)

## Оценка времени
3-4 часа
