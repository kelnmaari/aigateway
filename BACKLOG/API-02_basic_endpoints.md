# API-02: Базовые эндпоинты

## Описание
Реализация основных OpenAI-совместимых API эндпоинтов с заглушками.

## Задачи
- Создать handlers для основных эндпоинтов в `internal/api/handlers/`:
  - `GET /health` - health check
  - `GET /v1/models` - список моделей
  - `POST /v1/chat/completions` - chat completions (заглушка)
- Добавить middleware для аутентификации (API key)
- Реализовать базовую валидацию входящих данных

## Цель
Создать структуру основных API эндпоинтов для последующей интеграции с реальной логикой.

## Приоритет
**Высокий** - необходимо для MVP

## Фаза
2 - HTTP сервер и базовый роутинг

## Оценка времени
4-5 часов
