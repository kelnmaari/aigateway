# TUI-01: TUI Integration для API Keys

## Описание
Создание TUI интерфейса для управления API ключами через терминал.

## Задачи
- Создать API Keys management view в TUI
- Отображение списка ключей с статусами
- Создание нового API ключа через TUI
- Редактирование прав доступа к моделям
- Просмотр usage statistics по ключам
- Revoke/Enable ключей

## Цель
Предоставить удобный терминальный интерфейс для администрирования API ключей.

## Приоритет
**Высокий** - основной инструмент администратора

8 - API Key Management System
