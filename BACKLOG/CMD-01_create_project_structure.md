# CMD-01: Создание структуры проекта

## Описание
Инициализация нового Go проекта с базовой структурой директорий и настройкой инфраструктуры разработки.

## Задачи
- Создать Go модуль (`go mod init ollama-openai-proxy`)
- Создать базовую структуру директорий согласно архитектуре
- Настроить `.gitignore` для Go проекта
- Создать базовый `Makefile` с командами build/test/run
- Настроить базовый `docker-compose.yml` для разработки

## Цель
Подготовить основу проекта для дальнейшей разработки с правильной структурой директорий.

## Приоритет
**Высокий** - первая задача для старта проекта

## Фаза
1 - Инициализация проекта

## Оценка времени
1-2 часа
