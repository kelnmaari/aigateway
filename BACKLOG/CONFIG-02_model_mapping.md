# CONFIG-02: Конфигурируемый маппинг моделей

## Описание
Расширение системы конфигурации для гибкого маппинга и управления моделями.

## Задачи
- Расширить конфигурацию для маппинга моделей
- Добавить возможность задать алиасы для моделей
- Реализовать fallback механизм для недоступных моделей
- Добавить возможность скрыть некоторые модели

## Цель
Предоставить гибкие настройки для управления видимостью и именованием моделей.

## Приоритет
**Средний** - улучшает пользовательский опыт

## Фаза
5 - Model Manager

## Оценка времени
3-4 часа
