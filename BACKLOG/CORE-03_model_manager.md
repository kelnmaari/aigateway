# CORE-03: Model Manager

## Описание
Система управления моделями с маппингом, кешированием и проверкой доступности.

## Задачи
- Создать Model Manager в `internal/manager/model/`
- Реализовать функции:
  - Получение списка моделей из Ollama
  - Маппинг имен моделей (конфигурируемый)
  - Кеширование списка моделей
  - Проверка доступности моделей
- Добавить периодическое обновление списка моделей

## Цель
Обеспечить эффективное управление моделями с кешированием и маппингом.

## Приоритет
**Высокий** - необходимо для эндпоинта /v1/models

5 - Model Manager

## Оценка времени
4-5 часов
