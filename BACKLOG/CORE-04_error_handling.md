# CORE-04: Централизованная обработка ошибок

## Описание
Создание системы централизованной обработки ошибок с маппингом на OpenAI формат.

## Задачи
- Создать систему обработки ошибок
- Маппинг ошибок Ollama на OpenAI формат
- Добавить structured error responses
- Логирование всех ошибок с контекстом

## Цель
Обеспечить консистентную обработку ошибок и их корректное представление клиентам.

## Приоритет
**Высокий** - критично для production

## Фаза
7 - Обработка ошибок и устойчивость

## Оценка времени
3-4 часа
