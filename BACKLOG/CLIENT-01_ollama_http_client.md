# CLIENT-01: HTTP клиент для Ollama

## Описание
Разработка HTTP клиента для взаимодействия с сервером Ollama с поддержкой всех необходимых операций.

## Задачи
- Создать Ollama клиент в `internal/client/ollama/`
- Реализовать методы для:
  - Получения списка моделей
  - Отправки chat completion запросов
  - Обработки streaming responses
- Добавить connection pooling и retry логику
- Реализовать обработку ошибок и таймаутов

## Цель
Создать надежный клиент для коммуникации с Ollama сервером с устойчивостью к сбоям.

## Приоритет
**Высокий** - критичный компонент для работы прокси

## Фаза
3 - Ollama клиент

## Оценка времени
5-6 часов
