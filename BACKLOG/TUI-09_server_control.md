# TUI-09: Server Control

## Описание
Создание экрана для управления состоянием сервера и мониторинга его health.

## Задачи
- Кнопки управления сервером (Start/Stop/Restart)
- Отображение статуса подключения к Ollama
- Проверка health check эндпоинта
- Управление graceful shutdown
- Отображение uptime и статистики

## Цель
Предоставить централизованное управление сервером через TUI.

## Приоритет
**Средний** - полезно для операционного управления

## Фаза
11 - Terminal User Interface (TUI)

## Оценка времени
3-4 часа
