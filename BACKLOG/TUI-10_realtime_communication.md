# TUI-10: Real-time Communication

## Описание
Создание системы real-time связи между HTTP сервером и TUI для обновления данных.

## Задачи
- Реализовать канал связи между HTTP server и TUI
- WebSocket или IPC для передачи метрик
- Event-driven обновления в TUI
- Обработка concurrent доступа к метрикам
- Graceful handling разрыва связи

## Цель
Обеспечить актуальную информацию в TUI в реальном времени.

## Приоритет
**Высокий** - критично для эффективности TUI

## Фаза
12 - TUI Integration & Metrics

## Оценка времени
4-5 часов
