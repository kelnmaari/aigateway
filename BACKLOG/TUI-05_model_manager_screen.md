# TUI-05: Model Manager экран

## Описание
Создание интерфейса для управления моделями Ollama через TUI.

## Задачи
- Отображение списка доступных моделей из Ollama
- Показ статуса каждой модели (loaded/unloaded)
- Информация о размере модели и использовании памяти
- Возможность загрузки/выгрузки моделей
- Настройка алиасов моделей через TUI

## Цель
Предоставить удобный интерфейс для управления моделями.

## Приоритет
**Средний** - полезно для администрирования

## Фаза
11 - Terminal User Interface (TUI)

## Оценка времени
4-5 часов
